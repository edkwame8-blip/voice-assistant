# 🎙️ Voice Assistant

A Python-based voice assistant that listens for a wake word and controls your browser using voice commands.

## Features
- 🔍 Google search by voice
- 🌐 Open websites (YouTube, Google)
- 🕐 Tell the current time
- 🔊 Text-to-speech responses

## Requirements
- Python 3.x
- Google Chrome browser

## Installation

1. Clone the repository
   git clone https://github.com/edkwame8-blip/voice-assistant.git
   cd voice-assistant

2. Install dependencies
   pip install speechrecognition pyttsx3 selenium

3. Run the assistant
   python assistant.py

## Usage
Say the wake word **"assistant"** followed by a command:

| Command | Action |
|---|---|
| `assistant search Python tutorials` | Searches Google |
| `assistant open youtube` | Opens YouTube |
| `assistant open google` | Opens Google |
| `assistant what time is it` | Tells the time |
| `assistant quit` | Shuts down |
